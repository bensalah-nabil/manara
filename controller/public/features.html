Ce que fait Manara

Trois vidéos d’une minute pour voir comment Manara protège votre enfant. Rien de caché : votre enfant voit toujours ce qui est en place.

Vidéo 1 / 3

La nuit, les applis dorment

  • Vous choisissez l’heure du coucher.
  • TikTok, YouTube et les jeux se mettent en pause.
  • Les appels, les SMS, WhatsApp et le Coran restent ouverts.
  • Le matin, tout revient tout seul.
Vidéo 2 / 3

Un Internet plus sûr

  • Les sites pour adultes sont bloqués, dans Chrome et dans les applications.
  • La recherche Google reste en mode sécurisé.
  • En option : jeux d’argent, rencontres et alcool bloqués dans Chrome.
  • Les autres navigateurs sont fermés.
Vidéo 3 / 3

Les inconnus qui appellent

  • Vous écrivez les numéros que vous connaissez.
  • Un autre numéro, ou un numéro masqué, appelle ? Vous recevez une alerte.
  • L’appel est marqué dans l’historique.
  • Manara n’écoute jamais les appels.

Sur Android, avec la version téléchargée depuis le site.
