Open this page on your child's phone, then tap the button. Android 11 or newer.

Download Manara

About 5 MB. This link always gives the latest version.

Manara is not on Google Play yet, so Android asks for a few confirmations that a Play Store app wouldn't need. The steps below say what to expect. Manara is visible on the phone at all times: it shows a notice that the phone is managed and exactly what you can see.

Install it

  1. Tap Download Manara. If Chrome warns that this type of file can harm the device, choose to download it anyway.
  2. Open the downloaded file (from Chrome's notification or its Downloads list).
  3. If Android says the browser isn't allowed to install apps, tap Settings, turn on Allow from this source, and go back.
  4. Tap Install. If Google Play Protect offers to scan the app, let it. If it warns about the app, open its details to install anyway.
  5. Open Manara. Then, in the console on your own phone or computer, choose + Add a phone and follow the steps (see the parent guide).

Updating

Once setup has finished, Manara updates itself: it downloads a new version on Wi-Fi while the phone is charging, usually at night, and installs it without asking anything. Setup, rules and data are kept. To update by hand instead, download Manara from this page again and install it over the current copy.

Check that it is the real Manara

Every version is published, with its notes, on the releases page. Each copy is signed with the same key. Its certificate's SHA-256 fingerprint is:

14:99:E4:33:FB:89:F9:3D:9D:0F:C7:13:9D:F1:FD:3E:1B:76:53:6C:00:A3:CD:24:B2:9F:FB:81:C2:83:CA:61

Android refuses to install an update signed with a different key over Manara, so a fake copy can't replace it.
