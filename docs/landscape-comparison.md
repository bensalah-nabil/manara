# Open-source landscape: capability comparison against Manara

Verified on 2026-11-03.

- **Manara:** checked against its own source code in this repository.
- **Other projects:** checked against primary sources fetched that day: each repo's LICENSE file, README, `AndroidManifest.xml` and `build.gradle`, its releases and issues, and official docs or pricing pages. A few claims also rely on GitHub code search.

Nothing in this document comes from memory, forum posts or third-party lists. The "awesome parental controls" list found during research contained factual errors and is not used.

**Legend**

| Mark | Meaning                                                                                |
| ---- | -------------------------------------------------------------------------------------- |
| ✅    | Present, with a source                                                                 |
| ◐    | Partial, limited or paid; the cell says how                                            |
| ❌    | Absent. Used **only** when a source says so, or when the mechanism makes it impossible |
| ?    | Not found in any fetched source. This is **not** the same as absent                    |
| n/a  | The category doesn't apply, e.g. Device Owner for a router tool                        |

## 0. Corrections to *The Beacon Survey* and to this document's previous version

| Claim                                                                                                                                 | Verified reality                                                                                                                                                                                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| TimeLimit is AGPL-3.0                                                                                                                 | Only the **server** is AGPL-3.0. The Android app is **GPL-3.0**                                                                                                                                                                               |
| TimeLimit ships a Docker self-host image                                                                                              | It has a Dockerfile and a compose example that **builds from source**; no published image was found                                                                                                                                           |
| TimeLimit has Chrome allow/block lists                                                                                                | **Not in upstream.** This exists only in an unpublished fork that the unofficial `mpashka/timelimit-parent` console depends on                                                                                                                |
| TimeLimit has no Device Owner (previous version of this document)                                                                     | Device Owner is **optional** and only in the "direct" build. In that mode TimeLimit sets `DISALLOW_FACTORY_RESET` and `DISALLOW_SAFE_BOOT`                                                                                                    |
| OpenParental fork has "static-analysis notes, not APKs"                                                                               | **Wrong.** `abuzar310/openparental` contains the original FlashGet APKs (Git LFS) and JADX-decompiled code. It also adds a hidden icon, live screen capture with no prompt to the child, ambient audio recording, and call-log and SMS access |
| hagezi has no porn list                                                                                                               | **Wrong.** It has an NSFW list (92,021 domains) and a DoH/VPN/Tor/Proxy bypass list (16,579 domains)                                                                                                                                          |
| childscreentime is MIT                                                                                                                | Only its README says so. There is **no LICENSE file** (404) and no license in the GitHub sidebar                                                                                                                                              |
| KidSafe is active                                                                                                                     | Last release V1.1 was on 2019-07-13. The code is unchanged for 7 years; only the README was touched 4 years ago. Its open issue #5 is titled "App not being maintained."                                                                      |
| kid-phone-server is "very early, 3 stars"                                                                                             | The stars are accurate, but it is far along. The companion Device Owner launcher is at v0.52.7, released 2026-11-03. It has an on-device DNS VPN filter, offline schedules, SSE push and zero Google Mobile Services (GMS) dependency         |
| Headwind MDM: 567 stars                                                                                                               | That is the **legacy v5** panel (end of life December 2026). The current v7 panel has 1 star; the agent has 367                                                                                                                               |
| Headwind: remote lock, kiosk and allow-list (previous version of this document)                                                       | All three are **Enterprise (paid)** features, not Community                                                                                                                                                                                   |
| Headwind: URL filtering is a $990 add-on                                                                                              | It is one **combined Remote Control + URL Filtering** add-on, sold with Premium                                                                                                                                                               |
| FeurStagram: 693 stars, license unconfirmed                                                                                           | 1.2k stars, 73 forks; **GPL-3.0**                                                                                                                                                                                                             |
| AwayDoomscrollin': license unconfirmed, "no telemetry"                                                                                | **GPL-3.0-only.** The browser extension has no telemetry; the **Android app has opt-in telemetry**, off by default. Strict/Balanced modes cover Instagram and YouTube only, not TikTok                                                        |
| AdGuard Home `safesearch_enabled` flag                                                                                                | Deprecated since v0.107.27; replaced by a `safe_search` section. Parental Control sends a hash prefix of each domain to AdGuard's cloud service (off by default)                                                                              |
| Déchaîner has no time limits or app blocking (previous version of this document)                                                      | **Wrong.** It has per-app daily limits by weekday and app hide/suspend. It also blocks VPN **and** Private DNS configuration                                                                                                                  |
| Curbox has no time limits (previous version of this document)                                                                         | **Wrong.** It has per-app time windows. Its tamper protection uses Device Admin plus Accessibility, not Shizuku                                                                                                                               |
| "Manara is the only project combining Device Owner + bedtime + remote lock + self-hosted backend" (previous version of this document) | **Wrong.** kid-phone-server + kids-launcher-mdm does all of that and more. See §7                                                                                                                                                             |

## 8. Where Manara stands

### Closest peers

- **kid-phone-server + kids-launcher-mdm** has the same architecture (Device Owner agent + self-hosted server + web console) and is **further along** than Manara on almost every enforcement column.
- **TimeLimit** is the most mature parent → child tool. It has optional Device Owner and a self-hosted server, but no web filtering.
- **OpenParental** has the same no-covert principle, but rejects Device Owner by design.

### What actually differentiates Manara (verified)

Among parent → child tools, Manara is the only one that combines all of:

1. Device Owner enforcement
2. A self-hosted backend with a remote parent console
3. A permissive license (Apache-2.0)
4. A written no-covert rule, enforced in the policy schema

Why each peer misses at least one:

| Peer             | What it lacks                                                                 |
| ---------------- | ----------------------------------------------------------------------------- |
| kid-phone-server | GPL. Its messenger and browser forks journal the child's messages and history |
| TimeLimit        | GPL/AGPL. Device Owner is optional                                            |
| OpenParental     | No Device Owner                                                               |
| KidSafe          | Reads SMS; tied to Firebase                                                   |
| Headwind MDM     | An enterprise tool: no parental features, and remote lock is paid             |

That combination is real, but narrow. On features alone, Manara is **not** ahead.

## 9. Limits of this document

- **No device testing.** Only Manara has been run on a real device (SM-A045F). Every other row describes what each project's own sources say, not tested behaviour.
- **Code search is incomplete.** GitHub code search doesn't index every repo, so a feature not found by search is marked ?, never ❌.
- **Relative dates.** "3 days ago" and similar dates are as GitHub showed them on 2026-11-03.
- **Commercial products are out of scope.** Google Family Link, Qustodio, Bark and similar are not open source and aren't covered.
- **Effectiveness isn't measured.** Nothing here measures whether any of these tools actually reduces a child's phone use.
